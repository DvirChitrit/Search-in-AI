## Upload files and connect Claude to GitHub

If you want Claude to work with your project through GitHub, use this flow:

1. Put your project files in this repository folder.
2. Commit and push the files to GitHub.
3. In Claude, choose the GitHub connection/integration option.
4. Authorize GitHub access and select this repository (`DvirChitrit/Search-in-AI`).
5. Open the repository in Claude and start working from the latest branch/PR.

### Quick git commands

```bash
git add .
git commit -m "Add project files"
git push
```
